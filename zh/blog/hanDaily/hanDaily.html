Han 的日常短片 🎬 — 用 AI ，制作个人 IP 角色变成日常短片
结论

Han 是我设计的 Q 版 3D 个人 IP 角色。我在 TapNow上搭建AI 工作流，使用WorkBuddy与Agent协作：把灵感——一个安静的秋晨、一次宝石山登高、一段喝茶的片刻——变成一支角色始终如一的成片。以下日常短片，以及过程记录。

00三支短片

同一个角色，三段日常

每支短片都从一句想法和一份分镜表开始，再走一遍工作流。角色设定只做一次，后续每支片子都复用——所以三支短片的灵魂是同一个角色 Han，但每支片子都能有不同的灵感、场景、动作和情绪。

秋晨 · 咖啡与桂花鸟。一天的第一杯咖啡，窗外桂花枝头落一只小鸟——按下方分镜表逐镜生成。
宝石山 · 保俶与城隍。跟着角色登杭州宝石山，把保俶塔与老城地理收进一段安静的竖屏旅程。
捕捉灵感与茶。一段更慢、更氛围化的片子——一次茶歇，变成关于灵感从哪来的小小冥想。

01工作流

TapNow / Tapflow —— 五大模块，可克隆

整条工作流归纳节点图：角色设定 → 场景构思 → 视觉生成 → 音频 → 后期导出。角色设定只做一次、全程复用；其余环节都由一份文字 brief 和填空式提示词模板驱动，所以新片基本就是"换灵感、留骨架"。

  1. 角色设定（一次）。做 Han 的参考图与一致性锁，固定外观——帽子、衬衫、短裤、短靴，以及胸口三颗纽扣——让同一个角色在每支片子里都站得住，正面、侧面、背面皆然。
  2. 场景构思。一句话灵感 → 脚本 → 分镜（时间码、机位、光线、建议音效）。在生成前，确定分镜设定。
  3. 视觉生成。逐镜文生图首帧，再图生视频配合运镜；崩坏的镜用局部重绘修。
  4. 音频。生成 BGM 与分层 SFX、可选配音，混到时间轴上。
  5. 后期导出。按时间码剪辑，导出 MP4（H.264）。

提示词模板

可复用的结构化提示词

AI工作流除了内容生成逻辑外可服用的资产是提示词。总结在这个项目中关键节点「文生图（关键帧）」、「图生视频（分镜）」结构化提示词{{占位符}}。

# 文生图 · 首帧（逐镜） 主体 = {{角色，正面三扣 / 或侧背平整衣面}} 动作 = {{本镜动作}} 环境 = {{场景 / 天气 / 光线}} 情绪 = {{情绪基调}} 镜头 = {{景别 + 机位}} 风格 = 3D 动画电影感，柔光 规格 = 9:16 1080x1920 负向 = {{全局：背面纽扣，侧面圆饰，服装变体，写实真人}} + {{本镜专属}} # 图生视频（逐镜） 运镜 = {{推 / 拉 / 摇 / 升 / 环绕 / 跟}} 动态 = {{镜头或角色微动作}} 时长 = {{单镜秒数}} motion = {{0.25–0.7；抒情低、动作高}} seed_lock = on 一致性参考 = {{背面镜 → 背面帧；侧面镜 → 侧面帧}}
负向提示词是护栏：它保证 Han 的背面、侧面不长出正面才有的纽扣。
